# 용어집

| 용어 | 정의 |
|---|---|
| 공개 사이트 | 고객과 검색엔진이 접근하는 라오미펫 영업 사이트 |
| 관리자 | 후속 `/admin`에 로그인해 콘텐츠를 관리하는 운영자 |
| 운영자 | 은총쌤과 같이 매장 콘텐츠를 일상적으로 관리하는 사용자 |
| 시스템 관리자 | 스키마, 권한, 배포, 백업을 관리하는 개발자 계정 |
| Static Export | 빌드 시 HTML/CSS/JS를 생성해 정적 웹 서버에서 제공하는 방식 |
| SSG | 요청 시점이 아니라 빌드 시점에 페이지를 생성하는 방식 |
| 콘텐츠 스냅샷 | 특정 build가 사용한 콘텐츠 데이터의 고정된 JSON 결과 |
| 정적 파생본 | 원본 이미지를 공개 사이트에 맞게 리사이즈·압축·메타데이터 제거한 파일 |
| NAP | 상호명(Name), 주소(Address), 전화번호(Phone)의 일관된 표기 |
| 관리 backend | Spring Boot 기반 관리자 인증·콘텐츠 API |
| 관리자 UI | 후속 same-origin `/admin` 정적 화면 |
| 공개 상태 | `draft`, `published`, `archived` 중 콘텐츠 노출 상태 |
| 소프트 삭제 | DB 행을 제거하지 않고 `archived`로 바꾸어 고객 화면에서 제외하는 방식 |
| 원자적 배포 | 검증된 새 산출물로 한 번에 전환하고 실패 시 기존 사이트를 유지하는 방식 |
| 빌드 훅 | 콘텐츠 변경 후 정적 사이트 빌드를 요청하는 인증된 내부 호출 |
| 출시 게이트 | 조건이 충족되지 않으면 운영 배포를 금지하는 검증 항목 |
