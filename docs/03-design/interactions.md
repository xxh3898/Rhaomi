# 인터랙션

## 원칙

- 인터랙션은 신뢰 형성과 문의 전환을 보조해야 한다.
- 장식 목적의 무거운 JavaScript와 WebGL은 사용하지 않는다.
- 자동 재생 캐러셀을 사용하지 않는다.
- hover가 없어도 모든 기능을 사용할 수 있어야 한다.
- 애니메이션은 `prefers-reduced-motion`을 존중한다.

## Hero

- 최초 진입 시 텍스트와 이미지의 짧은 fade/translate 가능
- 스크롤 parallax는 최대한 약하게 적용하거나 생략
- LCP 이미지 로딩을 지연시키지 않는다.
- 모션 감소 환경에서는 정적 상태로 즉시 표시한다.

## 섹션 등장

권장 기본:

```text
opacity: 0 → 1
translateY: 16–24px → 0
duration: 300–500ms
```

- 콘텐츠를 CSS로 숨긴 채 JavaScript 성공에 의존하지 않는다.
- 관찰 실패 시에도 내용은 보여야 한다.

## 견종 필터

- `전체`가 기본 선택
- 선택 시 결과가 즉시 바뀐다.
- `aria-pressed` 또는 탭 패턴 중 하나를 일관되게 사용한다.
- 결과 개수와 빈 결과를 스크린리더가 인식할 수 있게 한다.
- 가로 스크롤은 드래그 없이도 버튼 탭과 키보드로 사용할 수 있다.

## 갤러리 상세

- 네이티브 `<dialog>` 또는 검증된 accessible dialog 사용
- 열 때 제목과 이미지 설명을 제공
- `Escape`로 닫기
- 닫을 때 트리거로 포커스 복귀
- 배경 스크롤 잠금
- 이전·다음 기능을 넣으면 버튼도 제공하며 swipe만 강요하지 않는다.

## 서비스 아코디언

- 버튼 요소 사용
- `aria-expanded`, `aria-controls`
- 여러 항목 동시 열기 여부를 명확히 결정
- 가격과 설명은 펼치기 전에도 검색엔진 HTML에 포함 가능

## 예약 문의 CTA

클릭 시 두 방식 중 구현 단계에서 선택한다.

1. 주요 외부 채널로 바로 이동
2. 접근 가능한 bottom sheet에서 채널 선택

bottom sheet를 사용하면:

- 제목
- 닫기 버튼
- 전화, 인스타그램, 네이버톡톡 중 유효 링크만 표시
- 외부 이동을 명시
- 포커스 관리

## Before/After

Phase 5 선택 기능이다.

- 드래그 외에 이전/이후 전환 버튼을 제공해야 한다.
- 키보드 조작이 가능해야 한다.
- 두 이미지의 의미를 대체텍스트와 캡션으로 제공한다.
