# SEO 전략

## 전제

Next.js 자체는 검색 순위를 보장하지 않는다. 이 프로젝트에서 Next.js Static Export를 선택한 이유는 핵심 콘텐츠와 메타데이터를 완성된 HTML로 제공하고, 빠른 정적 호스팅과 일관된 URL 생성을 구현하기 쉽기 때문이다.

검색 노출은 다음 요소의 결합 결과다.

- 검색 의도에 맞는 실제 콘텐츠
- 상호·지역·업종의 정확한 표현
- NAP 일치
- 크롤링 가능성
- 고유한 title과 description
- 구조화 데이터
- 모바일 사용성·성능
- 외부 플랫폼과 공식 채널의 일관성
- 지속적인 시술사진·공지 운영
- 검색엔진 정책과 경쟁 상황

## 목표 검색 의도

### 브랜드

- 라오미펫
- 라오미펫 애견미용
- 라오미펫 용인

### 지역·업종

- 용인 애견미용
- 용인 처인구 애견미용
- 처인구 애견미용
- 용인 강아지 미용

### 서비스·견종

- 용인 비숑 미용
- 용인 푸들 미용
- 용인 말티즈 미용
- 용인 강아지 목욕

키워드를 반복 삽입하지 않고 실제 문맥에서 지역, 서비스, 시술 사례를 설명한다.

## 정적 HTML 전략

- 홈의 핵심 매장정보, 서비스, 공지 요약, 갤러리 설명을 빌드 시 HTML에 포함한다.
- 공지 상세는 정적 URL로 생성한다.
- 검색 가치가 있는 견종 페이지는 콘텐츠 기준을 충족한 뒤 생성한다.
- 고객 브라우저에서 CMS fetch 후 텍스트를 주입하는 구조를 사용하지 않는다.
- JavaScript가 실패해도 전화, 지도, SNS 링크와 핵심 정보는 접근 가능해야 한다.

## 로컬 SEO

- 사이트, 네이버지도, 카카오맵, 블로그의 상호·주소·전화번호를 통일한다.
- 주소와 영업시간을 숨겨진 메타데이터가 아니라 화면에도 표시한다.
- `LocalBusiness` JSON-LD는 화면에 보이는 사실만 사용한다.
- 인스타그램과 네이버블로그를 `sameAs` 후보로 제공한다.
- 검증되지 않은 평점, 리뷰 수, 가격 범위를 구조화 데이터에 넣지 않는다.
- 도메인 확정 후 지도·블로그 프로필에 공식 사이트 링크를 추가한다.

## 콘텐츠 페이지

### 공지

- 고유 URL, title, description
- 게시일 표시
- 만료·보관 시 sitemap 제외
- 단순한 내부 공지는 `noindex`를 검토할 수 있으나 기본은 실제 고객 가치로 판단한다.

### 견종별 페이지

아래 기준을 모두 충족할 때만 생성한다.

- 해당 견종 공개 사진 3개 이상
- 중복이 아닌 고유 설명
- 대표 서비스와 실제 사례
- 유지 가능한 URL과 slug
- 빈 카드나 단순 필터 복제 페이지가 아님

기준 미달 시 홈의 인터랙티브 필터만 제공한다.

## 금지

- 숨김 텍스트
- 지역명·견종 키워드 반복
- 동일 콘텐츠 URL 양산
- 검색봇에게만 다른 콘텐츠 제공
- 사실과 다른 영업시간·가격·리뷰
- `robots.txt`로 비공개 데이터 보호
- 검색 순위 보장 표현

## 측정

- Google Search Console
- 네이버 서치어드바이저
- `site:<domain>` 확인
- 페이지별 검색 노출·클릭
- Search Console Core Web Vitals
- CTA 클릭과 검색 유입을 분리해 분석
