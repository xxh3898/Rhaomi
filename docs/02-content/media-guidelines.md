# 미디어 가이드

## 업로드 대상

- 실제 라오미펫 시술 결과
- 매장 내부
- 은총쌤 프로필
- Hero
- Open Graph 공유 이미지

## 사용 권한

- 직접 촬영했거나 게시 권한이 확인된 파일만 사용한다.
- 고객·보호자가 식별되는 사진은 명시적 동의 없이 사용하지 않는다.
- 다른 미용실, SNS, 검색 결과의 이미지를 복사하지 않는다.
- 상표, 전화번호, 차량번호, 주소 등 불필요한 식별정보가 배경에 없는지 확인한다.

## 촬영 권장

- 밝고 자연스러운 조명
- 반려견 얼굴과 전체 스타일이 선명한 구도
- 복잡한 배경 최소화
- 극단적인 필터와 과도한 보정 지양
- 세로 사진은 모바일 카드에 유리하도록 충분한 여백 확보
- 같은 시술의 Before/After는 유사한 각도와 거리 권장

## 업로드 입력

갤러리 게시 시 최소 입력:

- 사진
- 강아지 이름 또는 익명 표시
- 견종
- 서비스
- 짧은 설명
- 대체 텍스트
- 공개 상태

## 대체 텍스트

좋은 예:

```text
라오미펫에서 전체미용을 마친 흰색 비숑의 정면 모습
```

피해야 할 예:

```text
사진
강아지
용인 애견미용 용인 애견미용 비숑 미용
```

- 보이지 않는 정보를 추측하지 않는다.
- SEO 키워드를 반복하지 않는다.
- 주변 텍스트와 완전히 중복되면 더 짧게 쓴다.
- 장식 이미지에는 빈 alt를 사용한다.

## 파일 정책

- 원본은 후속 backend 소유 비공개 storage에 보관한다.
- 공개 사이트에는 빌드 파이프라인이 생성한 AVIF/WebP/JPEG 파생본을 사용한다.
- 공개용 파일에서 EXIF와 위치정보를 제거한다.
- 원본 파일명은 사용자에게 노출하지 않는다.
- 빌드 시 고유하고 안정적인 공개 파일명을 생성한다.
- 공개 파생본을 수동 편집하지 않는다.

## 초기 이미지 확보 체크

- Hero 1장
- OG 1장
- 갤러리 최소 6장 권장
- 은총쌤 소개 1장
- 매장 내부 1~2장
- 지도나 플랫폼 로고는 공식 사용 조건을 확인하지 않은 상태에서 임의로 이미지화하지 않는다.
