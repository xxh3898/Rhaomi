# ADR-006: 운영 삭제는 보관 처리

- 결정일: 2026-08-28
- 상태: Accepted

## 맥락

운영자가 모바일에서 실수로 공지나 시술사진을 삭제할 수 있다. 사진은 영업 자산이며 DB 행과 파일의 복구 시점이 다를 수 있다.

## 결정

운영자에게 영구 delete 권한을 주지 않는다.

```text
삭제 요청
→ status = archived
→ 정적 재빌드
→ 고객 화면에서 제거
```

영구 삭제는 시스템 관리자가 백업과 참조를 확인한 뒤 수행한다.

## 적용

- notices
- gallery_items
- breeds
- services

`shop_settings`는 삭제할 수 없다.

## 결과

### 장점

- 즉시 복구
- 관계 무결성 유지
- 파일 참조 보호
- 운영 실수 비용 감소
- 공개 제거 요구는 충족

### 비용

- DB와 uploads가 누적
- 정기 정리 필요
- 운영자에게 `삭제`와 `보관` 차이 설명 필요

## 영구 삭제 게이트

- 최근 정상 백업
- 참조 없음
- 공개 release에서 제거
- 법적·운영 보존 필요 없음
- 원본 파일의 다른 사용처 없음
- 삭제 대상 목록 기록

## 재검토 조건

- 보관 데이터가 저장공간 또는 관리 UI를 심각하게 방해
- 법적 삭제 요청에 더 빠른 완전 삭제 절차 필요
- Directus versioning과 별도 trash 기능으로 충분히 대체
