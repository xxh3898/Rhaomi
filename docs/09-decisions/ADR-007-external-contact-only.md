# ADR-007: 자체 예약·문의 폼 제외

- 결정일: 2026-08-28
- 상태: Accepted

## 맥락

사이트 목적은 고객이 정보를 확인하고 현재 운영 채널로 문의하게 하는 것이다. 자체 예약과 문의 폼은 개인정보, 운영 응답, 중복 예약, 알림, 보안, 법적 책임을 추가한다.

## 결정

1차에서 다음 외부 채널만 연결한다.

- 전화
- 인스타그램
- 네이버톡톡
- 카카오 채널 또는 카카오톡
- 네이버지도
- 카카오맵
- 네이버블로그

값이 없는 채널은 렌더링하지 않는다.

## 금지

- 고객 입력 폼
- 예약 시간 선택
- 예약 완료 표현
- 고객 DB
- 결제
- 자동 알림
- 네이버예약이 없는 상태에서 예약 가능하다는 오해

## 결과

### 장점

- 개인정보 최소화
- 기존 매장 운영 흐름 유지
- 개발·운영 범위 감소
- 중복 예약 책임 회피
- 외부 앱으로 빠른 전환

### 비용

- 문의 전환의 실제 완료를 사이트에서 측정하기 어려움
- 여러 채널 관리 필요
- 외부 플랫폼 장애와 로그인에 영향

## 재검토 조건

- 문의 누락이나 중복 예약이 반복 측정
- 월간 예약량이 수동 관리 한계를 넘음
- 운영자가 예약 정책과 슬롯을 관리할 준비
- 개인정보·알림·결제 운영 비용을 감당할 근거
