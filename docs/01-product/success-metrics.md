# 성공 지표

분석 도구와 개인정보 정책이 아직 확정되지 않았으므로 수치 목표는 출시 직전 확정한다.

## 1차 핵심 지표

### 문의 전환 행동

- 전화 버튼 클릭
- 인스타그램 클릭
- 네이버톡톡 클릭
- 네이버지도·카카오맵 클릭

### 신뢰 콘텐츠 소비

- 갤러리 도달률
- 견종 필터 사용률
- 사진 상세 열람률
- 예약 전 안내 도달률

### 검색 노출

- Google Search Console의 노출·클릭·검색어
- 네이버 서치어드바이저의 노출·클릭
- 상호명 검색 시 공식 사이트 수집 여부
- `용인 처인구 애견미용` 등 지역·업종 질의의 장기 추세

## 운영 지표

- 콘텐츠 게시 성공률
- 게시 후 정적 배포 실패 건수
- 최근 정상 백업 시각
- 복구 테스트 성공 여부
- 공개 사이트 가용성

## 계측 원칙

- 쿠키 기반 추적은 필요성이 확인되기 전 도입하지 않는다.
- 1차는 개인정보를 최소화한 페이지뷰·CTA 이벤트만 검토한다.
- 외부 분석 도구를 추가할 때 개인정보 처리방침과 동의 필요 여부를 별도 검토한다.
- 클릭 수를 실제 예약이나 매출로 동일시하지 않는다.
- 검색 노출은 기술, 콘텐츠, 플랫폼 정책과 경쟁 환경의 영향을 받으므로 보장 수치로 사용하지 않는다.

## 출시 후 검토 주기

- 출시 2주: 링크 오류와 사용 흐름
- 출시 1개월: 유입 채널과 CTA 사용
- 출시 3개월: 검색 노출 추세와 콘텐츠 운영 비용
- 기능 추가는 측정된 병목을 근거로 결정한다.
