# 제품 범위

## 1차 출시 포함

### 고객용 공개 사이트

- 모바일 우선 Hero
- 매장명, 대표 문구, 한 줄 소개
- 대표 이미지
- 전화·인스타그램·예약 문의 CTA
- 시술사진 갤러리
- 견종 필터
- 사진 상세 보기
- 은총쌤 소개
- 서비스 목록
- 가격 문구 또는 `상담 후 안내`
- 예약 전 안내
- 공지 목록과 공지 상세
- 주소, 영업시간, 휴무, 주차
- 네이버지도·카카오맵·인스타그램·블로그 외부 링크
- 네이버톡톡·카카오 링크는 값이 있을 때만 노출
- 하단 고정 CTA
- 404 페이지
- robots, sitemap, canonical, Open Graph, JSON-LD

### 관리자

- Directus 로그인
- 갤러리 등록·조회·수정·보관
- 공지 등록·조회·수정·보관
- 견종 등록·수정·비활성화
- 서비스 등록·수정·비활성화
- 기본 매장정보 수정
- 공개/초안/보관 상태 관리
- 이미지 업로드
- 정렬순서 관리
- 공개 콘텐츠 변경 후 자동 정적 배포

### 운영

- PostgreSQL 영속화
- Directus 업로드 파일 영속화
- 정적 산출물 Nginx 제공
- HTTPS
- 자동 백업
- 빌드 실패 시 기존 사이트 유지
- 이전 릴리스 롤백

## 명시적 제외

- 자체 예약 캘린더
- 예약 가능 시간 관리
- 고객 회원가입·로그인
- 결제
- 문의 폼
- 고객 DB와 CRM
- 리뷰 작성·동기화
- 네이버예약 연동
- 자동 문자·카카오 알림
- 실시간 채팅
- 쿠폰·포인트
- 다중 매장
- 다중 운영자 승인 워크플로
- 자체 방문자 분석 시스템
- 지도 임베드
- AI 이미지·문구 자동 생성

## 범위 변경 기준

아래 기능은 별도 제품 검증 없이 추가하지 않는다.

- 개인정보를 저장하는 기능
- 결제나 예약 상태를 책임지는 기능
- 고객과 매장 간 알림을 자동 발송하는 기능
- 외부 플랫폼 약관 또는 유료 API에 종속되는 기능

위 기능은 법적·운영적 실패 비용이 크므로 신규 ADR과 별도 릴리스 게이트가 필요하다.
